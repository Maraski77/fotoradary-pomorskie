# Mapa fotoradarów – województwo pomorskie

Interaktywna mapa fotoradarów w województwie pomorskim:
- fotoradary stacjonarne
- OPP (odcinkowy pomiar prędkości)
- red-light (przejazd na czerwonym świetle)
- heatmapa zagęszczenia

## Pliki
- `index.html` – główna strona
- `radars.json` – dane fotoradarów

## Uruchomienie

Settings → Pages → Deploy from branch → main → root
